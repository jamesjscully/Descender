## Derivation Rule

For each role, row band, row, and column, entries are generated by SHA-256
rejection sampling:

```text
SHA256(
  domain
  || role_u8
  || rows_per_commitment_u16_le
  || row_u16_le
  || col_u16_le
  || counter_u32_le
)
```

The digest is read as little-endian 16-bit chunks. The first chunk below:

```text
65535 - (65535 mod 12289)
```

is reduced modulo q.

This mirrors the existing q12289 matrix-generation style while adding explicit
role and row-band separation.

## KAT Coverage

The executable KAT proves:

- every role resolves to the expected column count;
- both 48-row and 64-row bands regenerate deterministically;
- every sampled entry is canonical `< q`;
- role separation changes matrix entries;
- row-band separation changes matrix entries and transcript digests;
- unsupported row bands reject;
- unknown roles reject;
- out-of-range rows and columns reject;
- all new domains participate in the global Path 2 duplicate/prefix check.
