# Product-Block Lee Sidecar Library, 2026-05-15

This directory is the first reusable sidecar library for the product-block Lee
route.  It was generated by:

```bash
cargo run --release --manifest-path tools/parameter-search/Cargo.toml \
  --bin product_block_lee_sweep -- \
  --q-values 12289,32771 \
  --eta-values 5,6,8,10 \
  --m1 32 \
  --rows-per-group-values 3,4,5 \
  --trials 8 \
  --seed 20260515 \
  --output-dir research/parameter_search/product_block_lee_sidecars_20260515
```

The sweep derives `target_l1 = ceil((q - 1) / (2 eta))` for each `(q, eta)`,
then searches exact two-coordinate product-block certificates.  Passing entries
are validator-ready sidecars for `product-block-lee`.

## Validator Use

The validator can load the whole library:

```bash
cargo run --release --manifest-path tools/parameter-search/Cargo.toml \
  --bin validate_frontier -- \
  --input-dir research/parameter_search/... \
  --output-dir research/parameter_search/..._validation \
  --shared-lee-cert-dir research/parameter_search/product_block_lee_sidecars_20260515
```

The smoke run in `frontier_rows4_eta10_smoke/` verifies that the directory
loader accepts a real frontier row with `q=32771`, `eta=10`,
`lee_repetition=1639`, and `lee_rows_per_group=4`.  That row validates through:

```text
research/parameter_search/product_block_lee_sidecars_20260515/q32771_m132_target1639_rows_per_group4.json
```

This is the first concrete structural improvement over the original single
`rows/group = 5` point: for eta 10 the q-ary amplitude proof object now uses
`64` pivot rows instead of `80`.
