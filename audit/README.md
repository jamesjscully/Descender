# Audit Notes

Status: ACTIVE_AUDIT_ENTRYPOINT

This directory contains theorem-audit outputs, red-team notes, and historical
proof-obligation burn-downs. It is evidence, not the current product authority
or top-level project tracker.

Current authority starts at:

- `../spec/README.md` for product/spec claims;
- `../spec/security_model.md` for current security-claim shape;
- `../spec/blockchain_requirements.md` for adoption gates and readiness;
- `../TRACKER.md` for implementation, proof, process, and adoption status;
- `../decisions/` for append-only project decisions.

When an audit file says "active path", "deployable target", or similar, read it
in the context of that file's date and the classification in
`../research/ARCHIVE_INDEX.md`. Older audit notes may still be valuable as
negative controls, proof-obligation history, or external-review seed material,
but they do not supersede the current spec spine or ADRs.
